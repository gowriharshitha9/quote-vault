# QuoteVault

An interactive front-end quote generator and aesthetic PNG social card exporter built with vanilla HTML, CSS, and JavaScript.

## Features
- **Category Filtering:** Browse curated quotes across Coding, Focus, Mindset, and Design.
- **Theme Switcher:** Switch seamlessly between Midnight, Pastel, and Minimal themes using CSS custom properties.
- **One-Click Copy:** Copy formatted quotes directly to the clipboard with instant visual feedback.
- **PNG Card Export:** Render and download high-resolution 1080×1080 quote cards matching the active theme using the HTML5 Canvas API.

## Technologies Used
- HTML5 (Semantic Markup & Canvas API)
- CSS3 (CSS Custom Properties, Flexbox, Responsive Layout)
- Vanilla JavaScript (ES6+, DOM Manipulation, Clipboard API)
